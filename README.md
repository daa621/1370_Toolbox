# 10/1370 Toolbox

Die Sammlung ist vollständig statisch und benötigt weder Installation noch Netzwerkzugriff.

## Start

`index.html` im Browser öffnen. Über die Karte **Tippstreifen** gelangt man zum unveränderten Tischrechner.

## Struktur

- `index.html` – Dashboard
- `styles.css` – dunkles Erscheinungsbild des Dashboards
- `tools/tippstreifen/` – unveränderte Kopie des bestehenden Tischrechners
- `tools/urlaub-rundung/` – Berechnung von Urlaubstagen und Zeitguthaben mit Druckansicht
- `tools/krankengeldzuschuss/` – Vorprüfung und Berechnung von Krankengeldzuschüssen
